# 🔐 CYBERHOME-LAB

## 📌 Présentation

CyberHome-Lab est un laboratoire de réseau domestique sécurisé réalisé avec Cisco Packet Tracer.

L'objectif est de construire, configurer et sécuriser un réseau domestique tout en mettant en pratique les notions fondamentales de réseau et de cybersécurité.

## 🎯 Objectifs

- Comprendre l'adressage IPv4
- Configurer un réseau local
- Configurer DHCP
- Comprendre et utiliser le WLAN
- Comprendre et utiliser les VLAN
- Configurer un routeur et un switch
- Sécuriser les équipements réseau
- Mettre en place des règles de contrôle d'accès
- Tester la connectivité et la sécurité du réseau

## 🛠️ Technologies utilisées

- Cisco Packet Tracer
- IPv4
- DHCP
- VLAN
- WLAN
- DNS
- ACL
- Réseaux LAN

## 🏗️ Architecture du projet

Le laboratoire représentera un réseau domestique comprenant :

- Un routeur
- Un switch
- Des ordinateurs
- Des appareils mobiles
- Un réseau Wi-Fi
- Un réseau invité
- Plusieurs segments réseau

## 🔒 Sécurité

Le projet sera progressivement sécurisé grâce à :

1. La configuration des mots de passe
2. La séparation des réseaux
3. Les VLAN
4. Les ACL
5. La limitation des communications entre certains appareils
6. Des tests de sécurité dans un environnement de laboratoire

## 📚 Compétences développées
